# Розширення протоколу DNIP

**Розширення протоколу** — це механізм, який дозволяє доповнювати базовий функціонал протоколу DNIP новими можливостями без порушення сумісності між сервісами.  
Завдяки цьому підхід DNIP залишається гнучким, масштабованим та здатним до еволюції без необхідності повної зміни основного протоколу.

### 🎯 Основна ідея
Розширення додають нові типи повідомлень, подій або методів взаємодії між компонентами системи, не змінюючи ядро протоколу.  
Кожне розширення описується окремим модулем і може бути:
- **системним** (офіційно описаним у конвенції DNIP);
- **кастомним** (створеним для конкретного проєкту або організації).

### ⚙️ Принцип роботи
1. **Базовий протокол** визначає обов’язковий набір структур даних і правил обміну.  
2. **Розширення** підключається як додатковий шар, що додає нові можливості або уточнює поведінку існуючих.  
3. Сервіси, які не підтримують певне розширення, просто ігнорують його, зберігаючи стабільність комунікації.

### 🧩 Приклади використання
- Додавання нових типів команд у Gateway.
- Підтримка специфічних форматів даних у Service.
- Введення експериментальних функцій для тестування.

### 🛠 Структура розширення
Типове розширення включає:
- **Ідентифікатор розширення** (унікальне ім’я);
- **Версію**;
- **Опис нових методів або полів**;
- **Правила сумісності** з базовим протоколом.

### 🧱 Переваги підходу
- ✅ Модульність і легке оновлення;
- ✅ Зворотна сумісність між версіями;
- ✅ Можливість поступового впровадження нових можливостей;
- ✅ Зменшення ризику збоїв при масштабуванні системи.
