# Валідація
> Схеми контрактів описані у [Контракти](contracts/05-contracts.md).  
> Опис cronjobs див. у [Cron](execution/10-cron.md)

**Платформа, яка розуміє DNIP,** виконує два типи валідації:

- **Статична на старті** — валідація **`protocol.json`** за стандартом DNIP  
  (**fail-fast**: помилка у `protocol.json` → вузол **не стартує**).
- **Динамічна під час виконання (realtime)** — валідація **`input`**, **`output`** та **`headers`** для кожного виклику.

---

## 🛡️ Статична валідація `protocol.json`

Після завантаження вузла Платформа:

- зчитує **`protocol.json`**;
- перевіряє його за офіційною схемою DNIP (домени, дії, `processors`, `cronjobs`, `gateway`, посилання на контракти, `execute`, `onError`, `onComplete` тощо);
- застосовує **fail-fast тільки для `protocol.json`**: при будь-якій помилці вузол **не стартує**.

> Валідація контрактів не блокує старт — вона виконується **realtime** при кожному виклику.

---

## ⚡ Динамічна валідація контрактів

Для кожної дії, події чи процесора, якщо визначено контракт (див. [Контракти](05-contracts.md)):

- валідовує **`input`** (схема вхідних даних);
- валідовує **`output`** (схема вихідних даних);
- валідовує **`headers`** (якщо вони описані у контракті).

Успішно провалідоване `input` формує **`context.params`**,  
а Платформа додає **`context`** (адаптери, заголовки, службові поля: `error`, `requestId` тощо).

> **Cronjobs** не мають контрактів, тому отримують лише `context`.

---

## Рекомендації до схем

- Використовуйте унікальні `$id` для кожної схеми.
- Явно вказуйте `type`, `required`, `additionalProperties`.
- Застосовуйте `format` та `pattern` для підвищення якості валідації.
- За потреби додавайте службові метадані (наприклад, `x-meta/status_code`).

---

## Помилки валідації

- **`input` invalid** → помилка запиту (наприклад, 400 у HTTP gateway).
- **`output` invalid** → помилка виконання (наприклад, 500), може викликатися `onError` з `protocol.json`.
- **`headers` invalid** → помилка автентифікації чи транспорту (наприклад, 401/403), залежно від контексту.
